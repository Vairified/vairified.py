`client.events.withdraw()` takes one of your listings out of the Vairified directory, addressed by the same `partner_event_id` you submitted it under. A programme that is cancelled, finished or unpublished on your own site keeps its directory row until you say otherwise, and that row keeps sending players to a page that no longer takes them — worse than never having listed it. It is reversible: submitting the same `partner_event_id` again restores the listing at the same Vairified id, so links you have already shared keep working. It is idempotent: withdrawing something already withdrawn succeeds with `withdrawn=False`, so a batch is safe to retry. You can only withdraw your own, and an identifier that is not yours is reported as not found rather than forbidden, so this cannot be used to discover what anyone else has listed. Adds the frozen model `WithdrawnEvent`. `client.events.list()` also gains `mine=True`, the other half of reconciling a catalogue: to withdraw a listing you must first be able to discover it, so this returns only the events you submitted — withdrawn ones excluded, because a reconciler is asking what is live. It requires an API key linked to a partner application.
